# Modifying your agent

Once you've created a custom agent, you can modify it at any time via the **\[ My agents ]** tab on your **\[ Agents ]** page for your personal workspace or organization. You have a few options:

* [Profile](profile.md)
  * Changing name and discoverability
* [Agent](agent-settings.md)
  * For modifying language model, prompt and agent harness
* [Context](context-markdown-websites-pdf.md)
  * Managing markdown, documents and websites
* [Toolkits](installing-tools.md)
  * Installing and managing tools
* [Keychain](secrets-and-security.md)
  * Managing secrets for open source tools
* [Connections](third-party-connections.md)
  * Linking to Discord
